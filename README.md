# Predictive Maintenance System

Project focused on predictive maintenance using data analysis, machine learning, and dashboard visualization.

## Technologies

- Python
- Pandas
- Scikit-Learn
- Streamlit
- Git
- GitHub

## Objective

Predict machine failures using operational data.

## Dataset

This project uses the AI4I 2020 Predictive Maintenance Dataset.

Source: <https://www.kaggle.com/datasets/stephanmatzka/predictive-maintenance-dataset-ai4i-2020/data>
